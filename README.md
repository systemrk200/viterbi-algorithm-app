# 🔤 Viterbi Algorithm App — сегментация текста

Кроссплатформенное десктопное приложение на **Avalonia UI**, которое разбивает строку без пробелов на слова, используя **алгоритм Витерби** (динамическое программирование) и статистическую модель, обученную на введённом тексте.

Например, `мамамылараму` → `мама мыла раму`.

![Скриншот приложения](docs/screenshot.png)

## ✨ Возможности

- Обучение на произвольном тексте прямо в интерфейсе
- Подсчёт частот слов и вычисление логарифмов вероятностей
- Разбиение слитной строки на слова по максимуму правдоподобия
- Поддержка русского алфавита (включая `ё`)
- Автоматическая нормализация входа: регистр, удаление знаков препинания и пробелов
- Оптимизация перебора за счёт ограничения по максимальной длине слова
- Информативные сообщения о статусе (пустой текст, невозможность разбиения и т.п.)
- Кроссплатформенность: Windows, macOS, Linux

## 🛠️ Технологии

- **C# / .NET**
- **[Avalonia UI](https://avaloniaui.net/)** — кроссплатформенный UI-фреймворк
- **System.Text.RegularExpressions** — извлечение слов из текста
- **Алгоритм Витерби** — поиск оптимального разбиения строки

## 📋 Требования

- [.NET SDK](https://dotnet.microsoft.com/download) версии 6.0 или выше
- (опционально) IDE: Visual Studio 2022, JetBrains Rider или VS Code с расширением C#
