# 🔤 Viterbi Segmentation — разбиение строки на слова алгоритмом Витерби

Кроссплатформенное десктопное приложение на **Avalonia UI**, которое восстанавливает границы слов в слитно записанной строке (например, `мамамылараму` → `мама мыла раму`) с помощью **алгоритма Витерби** на основе статистической модели, обученной на произвольном тексте.

![Скриншот приложения](docs/screenshot.png)

## ✨ Возможности

- **Обучение модели** на любом тексте с пробелами — приложение само строит словарь слов и их логарифмических вероятностей
- **Работа с русским языком**: корректно обрабатываются буквы `Ё`/`ё`, регистр приводится к нижнему
- **Алгоритм Витерби** находит разбиение с максимальной суммарной логарифмической вероятностью
- **Оптимизация по максимальной длине слова** — лишние подстроки не перебираются
- Информативный статус: количество слов в словаре и максимальная длина
- Понятные сообщения об ошибках (пустой обучающий текст, пустая строка, невозможное разбиение)
- Кроссплатформенность: Windows, macOS, Linux

## 🛠️ Технологии

- **Алгоритм Витерби** — динамическое программирование для поиска оптимальной сегментации

```bash
git clone https://github.com/ваш-username/viterbi-segmentation.git
cd viterbi-segmentation
```

Восстановите зависимости и запустите:

```bash
dotnet restore
dotnet run
```

Либо откройте файл решения (`.sln`) в вашей IDE и нажмите **Run / F5**.

## 🎯 Использование

1. **Обучение**:
   - Вставьте в верхнее поле текст, содержащий слова через пробелы (например, `мама мыла раму мылом мыла`).
   - Нажмите **«Обучить»**.
   - В строке статуса появится количество слов в словаре и максимальная длина слова.
2. **Сегментация**:
   - Введите строку без пробелов в нижнее поле (например, `мамамылараму`).
   - Нажмите **«Разбить»**.
   - В блоке «Результат» появится разбиение с пробелами.

### Пример

**Обучающий текст:**
```
мама мыла раму мылом мыла
```

**Строка для разбиения:**
```
мамамылараму
```

**Результат:**
```
мама мыла раму
```

## 🔬 Как это работает

### 1. Обучение модели

- Из обучающего текста извлекаются все последовательности русских букв (регулярное выражение `[А-Яа-яЁё]+`).
- Каждое слово приводится к нижнему регистру, ведётся подсчёт частот.
- Для каждого слова вычисляется логарифм вероятности:

  $$P(w) = \frac{\text{count}(w)}{\text{total words}}, \qquad \log P(w)$$

- Запоминается максимальная длина слова `_maxWordLength` — для оптимизации перебора.

### 2. Алгоритм Витерби

Над строкой `s` длины `n` строится массив `dp[0..n]`:

- `dp[i]` — максимальная суммарная логарифмическая вероятность разбиения префикса `s[0..i)`.
- `back[i]` — индекс начала последнего слова в оптимальном разбиении.
- Перебираются только подстроки длиной не больше `_maxWordLength` — это отсекает заведомо невозможные варианты.
- Восстановление пути по массиву `back` даёт последовательность слов.

Если `dp[n]` остаётся «минус бесконечностью», значит строку невозможно разбить словами из словаря — выводится соответствующее сообщение.

### 3. Сложность

- По времени: `O(n · L)`, где `n` — длина строки, `L` — максимальная длина слова в словаре.
- По памяти: `O(n)`.
